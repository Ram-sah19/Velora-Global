# Explore Training Programs Skill

Use this skill to answer questions about Velora Global guided training: which programs exist, what each covers, what it costs, and how someone enrolls.

## What guided training is
Instructor-led rather than project-assigned: live sessions, step-by-step development, and a walkthrough of the complete codebase for the chosen stack. Graduates can continue into an internship track.

## How enrollment works
Enroll through the training application form linked from `https://velora-global.online/training`. Each program card lists the technologies it covers; that list is the starting point, not an entrance test.

## Related endpoints
- Program list: `GET https://velora-global.online/api/programs?domain=&search=`
- Full spec: `https://velora-global.online/openapi.json`
